# 🏆 Easytournament

Easytournament is a modern web application designed to effortlessly create and manage normal leagues and money/prize-pool tournaments[span_0](start_span)[span_0](end_span). Whether you are organizing local gaming competitions or professional esports leagues, this platform streamlines tournament setup, fixture management, and participant tracking.

## 🚀 Features

- **Tournament Creation:** Set up normal leagues or paid/money tournaments with custom rules[span_1](start_span)[span_1](end_span).
- **Participant & Team Management:** Easily register, track, and manage competing teams or players.
- **Fixtures & Standings:** Automated or manual generation of match schedules and live league tables.
- **Progressive Web App (PWA) Ready:** Includes manifest and service workers (`sw.js`) for seamless mobile and desktop experience.
- **Responsive UI:** Clean and responsive user interface optimized for all screen sizes.

## 🛠️ Tech Stack

This project is built using modern web technologies:
- **Frontend:** HTML5[span_2](start_span)[span_2](end_span), CSS3, JavaScript (ES6+)[span_3](start_span)[span_3](end_span)
- **Backend:** Node.js[span_4](start_span)[span_4](end_span), Express (`server.js`)[span_5](start_span)[span_5](end_span)
- **PWA Configuration:** Web Manifest & Service Workers (`sw.js`)
